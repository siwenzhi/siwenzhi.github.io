国自然青年基金河南省科学技术进步二等奖

面向多源异构知识的融合与检索需求，以百度百科、快懂百科及高校官网等多源数据为基础，经数据采集、知识抽取与图谱构建，实现异构知识的语义对齐、冲突判断与融合补全，并提供知识检索与图谱可视化功能。

Spring BootVue 3SeleniumMySQLRedisLLM知识图谱NER
  1. 多源异构数据采集：基于 Selenium 构建自动化数据采集模块，对同一实体的多源描述进行抓取、清洗与本地化存储，为后续知识抽取与图谱构建提供数据基础。
  2. 知识图谱构建：对各数据源独立进行实体、属性及关系抽取，完成结构化知识表示，并分别构建知识图谱，保留知识来源信息，避免不同来源数据在融合前发生信息污染。

03

基于 RAG 的营养知识问答平台

2024.10 — 2025.04项目负责人

企业项目

整合《中国居民膳食指南》、食品营养成分表等相关资料，结合 LLM 与 RAG 技术，开发面向日常饮食场景的食品营养智能问答系统，为用户提供食品营养查询、营养成分分析、饮食搭配及健康饮食知识问答服务。

vLLMPaddleOCRLangChainVue 3RedisElasticsearchBM25RRFQwen3-Embedding-8BBGE-Reranker
  1. 知识库构建：使用 PaddleOCR 对膳食指南、营养科普等文档进行文本识别与解析，完成文本数据清洗、语义分块与元数据标注；基于 vLLM 本地部署 Qwen3-Embedding-8B 完成文本向量化，结合 Elasticsearch 构建食品营养领域知识库，实现文本与向量统一索引。
  2. 查询优化：针对食品别名、口语化描述及复杂饮食问题，结合历史对话进行用户意图提取及 Query Rewrite，将自然语言查询转换为结构化检索条件；Redis 保存多轮会话上下文，增强连续问答的语义理解能力。
  3. 检索与消歧优化：基于 Elasticsearch 实现 BM25 与向量检索双路召回，通过 RRF 融合多路检索结果；使用 Reranker 对候选知识片段进行相关性重排序，结合元数据过滤、文档去重与 Top-K 截断优化最终上下文，兼顾精确匹配与语义召回，提升食品营养知识检索的准确性。
  4. 生成与回答优化：基于 Spring AI 编排完整 RAG 问答链路，通过 Few-shot + CoT 引导模型结合检索证据完成食品营养分析与饮食建议，并在回答中返回对应知识来源，提高回答的专业性、可解释性与可追溯性。
  5. 系统交互与性能优化：使用 Vue 3 实现流式问答、历史会话及知识来源展示，使用 Redis 缓存高频问答结果，降低重复检索及模型调用开销。
04

基于TF-IDF的学术论文检索算法研究与实现

2023.04 — 2023.12项目负责人

校级科研课题河南省优秀学士学位论文

面向高校学术论文管理与检索场景，针对传统关键词匹配存在语义区分度不足、检索结果相关性不高等问题，研究基于 TF-IDF 的文本特征表示与论文相关性计算方法，设计并实现面向论文题目、摘要及关键词等文本信息的学术论文检索系统。

Spring BootVueMySQLTF-IDFBM25中文分词文本相似度计算
  1. 论文文本预处理：对论文题目、摘要、关键词等文本进行中文分词、停用词过滤及文本规范化处理，构建论文语料库与词项索引，为后续特征计算与检索提供基础。
  2. TF-IDF 特征建模：基于词频（TF）与逆文档频率（IDF）计算词项权重，将论文文本转换为高维特征向量，降低高频通用词对检索结果的影响，增强具有区分度关键词的权重。
  3. 论文相关性检索：对用户查询进行同样的文本预处理与特征表示，通过向量相似度计算查询与候选论文之间的相关程度，并结合 BM25 等文本相关性指标进行排序，返回相关论文结果。
  4. 检索系统实现：基于 Spring Boot + Vue 实现论文管理与检索功能开发，MySQL 存储论文元数据及相关信息，实现论文录入、条件查询、全文检索与相关度排序等功能。
